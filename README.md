# Ein HaBesor Butchery – Online Ordering Platform

A web-based ordering platform developed for a local butcher shop in Ein HaBesor, Israel.

The platform provides customers with a simple and intuitive way to browse available products, select quantities, calculate order totals, and submit orders directly through WhatsApp.

## Overview

This project was developed as a practical web solution for a local business, with a focus on usability, clear product presentation, and a streamlined ordering process.

Instead of requiring a dedicated e-commerce system, the website connects the customer directly with the business through WhatsApp, making the ordering process fast and accessible.

## Key Features

* **Product Gallery** – Visual presentation of available meat products.
* **Dynamic Quantity Selection** – Customers can increase or decrease the quantity of each product.
* **Real-Time Price Calculation** – The total order price is automatically updated according to the selected quantity.
* **WhatsApp Integration** – Generates an order summary and opens WhatsApp with the order details ready to send.
* **Waze Integration** – Provides direct navigation to the physical store.
* **Hebrew RTL Interface** – Designed specifically for Hebrew-speaking users.
* **Simple User Experience** – Clear layout and straightforward ordering flow.

## Technologies

* **HTML5** – Semantic structure and page content
* **CSS3** – Layout, styling, and visual design
* **JavaScript** – Dynamic interactions, quantity management, price calculation, and order generation
* **WhatsApp Integration** – Customer order submission
* **Waze Integration** – Location and navigation

## Application Flow

```text
Browse Products
      ↓
Select Quantity
      ↓
Calculate Total
      ↓
Generate Order Summary
      ↓
Open WhatsApp
      ↓
Send Order to the Business
```

## JavaScript Functionality

The website uses JavaScript to handle the main interactive functionality:

* Managing the selected product quantity
* Preventing invalid quantities
* Calculating the total price dynamically
* Generating a personalized order message
* Encoding the order information for WhatsApp
* Opening the WhatsApp order link in a new window

## Business Value

The platform provides a lightweight digital ordering solution for a local business without requiring a complex e-commerce infrastructure.

It simplifies the customer journey while allowing the business to receive structured orders directly through an existing communication channel.
